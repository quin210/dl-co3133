# AI Usage Disclosure — CO3133 Deep Learning and Its Applications (Semester-261)

This document discloses how generative AI tools were used in the course project, as
required by Section 5 of the course handbook. Usage is organised by **purpose** rather
than by individual session. A dated usage log is provided at the end of the file.

## Statement of Responsibility

The group takes full responsibility for all submitted code, numbers, figures, claims and
narrative. AI tools were used as **assistants for learning, ideation and language
editing**, not as substitutes for the group's own work. In particular:

- No experimental results, metrics, figures or data were generated by AI.
- No end-to-end pipeline (data loading, training, evaluation) was produced by AI.
- Every AI-assisted contribution was reviewed, edited and verified by the group against
  source code, real runs, official documentation or published references.
- Every member is able to explain any part of the submission on request.
- **Exception, Assignment 2 M3 (Section 6):** an AI coding agent edited code, ran the
  group's training and evaluation scripts for the GPU follow-up runs, and drafted the M3
  report. The results it reports come from real runs of the committed scripts; they were
  not written by hand or invented. Section 6 lists exactly what it did and how the group
  checked it.

## 1. Ideation

- **Purpose:** Brainstorming how to approach and structure the assignment, and discussing
  possible directions before implementation.
- **Stage:** Planning phase of each milestone.
- **Scope of AI contribution:** High-level suggestions only, such as how to organise the
  analysis, which questions a section should answer, or which trade-offs to consider.
- **Representative prompt:** *"What aspects should a comparative study of linear, MLP and
  CNN classifiers on Fashion-MNIST address?"*
- **How output was used and verified:** Suggestions were treated as a starting point for
  group discussion. Final decisions were made by the group and checked against the
  handbook requirements (Parts I–II).
- **Verification sources:** Course handbook; group discussion.

## 2. Presentation and English Language

- **Purpose:** Grammar correction, wording and clarity of English text.
- **Stage:** Writing and revising the notebook narrative, website pages and report.
- **Scope of AI contribution:** Sentence-level rephrasing and grammar fixes on text
  written by the group. No new content, claims or numbers were introduced.
- **Representative prompt:** *"Fix the grammar and improve the clarity of this paragraph
  in academic English without changing its meaning or any numbers."*
- **How output was used and verified:** Each edit was compared against the original to
  confirm that meaning, technical terminology and all numbers (sample counts,
  statistics, metrics) were unchanged. Edits that altered meaning were rejected.
- **Verification sources:** Manual comparison with the original text and notebook outputs.

## 3. Learning from Code Examples

- **Purpose:** Understanding unfamiliar APIs or concepts through **generic, standalone
  examples**, so that the group could then write the project code independently.
- **Stage:** Implementation phase, when a concept or library function was unclear.
- **Scope of AI contribution:** Small illustrative examples unrelated to the project's
  actual pipeline, together with an explanation of the expected output and what each
  line does.
- **What AI was not used for:** AI did not write the project's data pipeline, models,
  training loop or evaluation code as a whole. The project code was written by the
  group, applying what was learned from these examples.
- **How output was used and verified:** Concepts were cross-checked against official
  documentation and confirmed by running small tests before being applied in the project.
- **Verification sources:** PyTorch documentation; scikit-learn documentation; local test runs.

## 4. Extension Ideas from External References

- **Purpose:** Identifying ideas for deeper or additional analysis by consulting
  professional external references.
- **Stage:** After the core requirements were implemented.
- **Scope of AI contribution:** Pointing to or summarising relevant public references
  (official documentation, GitHub repositories, published papers, tutorials) and
  suggesting what else could be analysed. For example, in the EDA, suggestions for
  additional analyses beyond the mandatory items (class distribution, input size,
  imbalance, representative samples).
- **How output was used and verified:** The group read the original references
  directly, judged their relevance, and selected which ideas to adopt. Every adopted
  analysis was implemented and run by the group on the actual dataset, and its
  interpretation was checked against the produced outputs.

## 5. Slide Preparation

- **Purpose:** Support in preparing the presentation slides for Assignment 1.
- **Stage:** After the experiments and report were finished.
- **Scope of AI contribution:** Suggestions on slide structure and flow, and
  wording/layout refinement of slide text drawn from the group's own report. No new
  results, metrics, figures or claims were introduced by AI.
- **How output was used and verified:** The group wrote and selected all slide content,
  checked every number and figure on the slides against the report and the actual run
  outputs, and rejected suggestions that changed meaning.
- **Verification sources:** Group report; saved run outputs (`metrics.json`, `history.csv`).

## 6. Assignment 2 M3: coding agent for follow-up experiments and report draft

- **Used by:** Võ Thị Như Quỳnh.

    executed `03_analysis.ipynb`.

    `02_results.ipynb`; fixed one typo in `02_results.ipynb`; added the reproduction
    section of `README.md`.
  - *Report writing:* first draft of the A2 M3 LaTeX report, built from the notebooks,
    the M2 report and the handbook requirements.
  - *Slides:* first draft of the A2 M3 slides (`docs/reports/A2_M3_slides.pdf`), built from
    the numbers and figures of the report.
- **Affected files / sections:** `Assignment2/train.py`, `evaluate.py`,
  `models/backbones.py`, `03_analysis.ipynb`, `configs/a2.yaml`, `README.md`;
  A2 M3 report, all sections (text), in particular 2.3.3, 2.6, 3.8 and 3.11.
- **Representative prompt:** "Read the handbook requirements for Assignment 2 and complete
  the M3 final: run more experiments if needed, follow the style of Assignment 1, and write

- **How the output was edited and verified:** the CPU results of the main study (E1, E2)

- **Responsible member for final verification:** Võ Thị Như Quỳnh.
- **Verification sources:** PyTorch and torchvision documentation; the cited papers

  executed `01_eda.ipynb`; the split is checked by assertions in `data_loader.py` (no image

  cross-attention. The group reviews the code and the text before submission.

- **Verification sources:** A-OKVQA paper and dataset card; CLIP paper; course slides
