Image classification on Fashion-MNIST

Problem

How do image representations affect classification accuracy and computational cost? We compare Linear, MLP, CNN, LSTM and Transformer on Fashion-MNIST: ten clothing classes represented by 28 × 28 grayscale images. Similar upper-body silhouettes make some categories difficult to separate.

Experimental setup

A stratified seed-42 split gives 54,000 training, 6,000 validation and 10,000 test images. All models use training-only normalization, Adam at 0.001, batch size 128 and 16 epochs on four CPU threads. Validation macro-F1 selects each checkpoint. Full protocol.

CNN reaches 91.05% test accuracy, 2.28 percentage points above MLP with roughly half the parameters. MLP offers faster inference; CNN takes about 14× as long per image on this CPU.

Training time includes validation and checkpoint work. Inference is batched throughput, measured as the median of three passes after warmup. Metric definitions.

Upper-body clothing remains the main source of confusion: CNN labels 165 of 1,000 T-shirts as Shirt. Error analysis examines the class pairs and prediction examples. These results cover one seed, one split and a fixed training budget; variability across runs has not been measured.
