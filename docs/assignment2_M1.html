Dataset

  • Name: Tomato Leaves Dataset.
  • Source: shreemunale/tomato-leaves-dataset on Hugging Face, combining tomato images from PlantVillage and PlantDoc.
  • Version: repository revision c029791.
  • Licence: CC BY 4.0, as listed by the dataset repository.
  • Task: image classification into seven disease categories and one healthy category.
  • Input: a tomato-leaf image, converted to RGB and resized to 224 × 224 for the models.
  • Annotation: one class label per image.

Class labels

  • 0: Bacterial spot
  • 1: Early blight
  • 2: Late blight
  • 3: Leaf mold
  • 4: Septoria leaf spot
  • 5: Tomato yellow leaf curl virus
  • 6: Tomato mosaic virus
  • 7: Healthy

Size and split

  • Total: 17,996 images across eight classes.
  • Training: 14,404 images.
  • Validation: 1,796 images.
  • Test: 1,796 images.
  • Selection: use all eight classes and all valid images.
  • Leakage prevention: keep each original photograph and its identifiable copies, augmentations, and crops in the same partition.

Proposed method

  • Baseline: train a small CNN from scratch.
  • Pretrained model: ImageNet-pretrained ResNet-18 with an eight-class output head.
  • Comparison: frozen backbone versus full fine-tuning.
  • Metrics: accuracy and macro-F1; select checkpoints using validation macro-F1.
